# Nav Mesh Commands in Dedicated Servers

Some nav mesh commands can be used in a dedicated server console, either directly via terminal or via RCON.    

## Usable Commands

The following is a list of commands that can be used in a dedicated server.    
Note that most commands requires `sv_cheats 1`.    

| Command Name |
|:---:|
|sm_nav_area_fix_bad_dropdowns|
|sm_nav_auto_create_teleports|
|sm_nav_debug_blockers|
|sm_nav_generate|
|sm_nav_import|
|sm_nav_rcbot2_import|
|sm_nav_reload|
|sm_nav_save|
